Customer Support Chatbot — demo page

The blue circle in the bottom-right is the chatbot launcher. Click it to open the widget.

Before testing live: edit this file and set window.CHATBOT_WEBHOOK_URL to your n8n webhook URL (the one the Webhook node in workflow.json exposes).

Try messages like:

  • "What's your return policy?" → routes to qa
  • "Where is order ORD-1001?" → routes to order_lookup (needs seed data)
  • "My order arrived damaged, can I get a refund?" → routes to ticket_create
  • "Can I talk to a human?" → routes to handoff
